# L1-H2 Side-View Playtest Target

The first H2 prototype proved boarding -> on-foot handoff, but its top-down perspective was rejected in playtest.

Canonical interior direction is now locked:

- side-view traversal, not top-down
- horizontal left/right movement
- gravity and jumping
- responsive jump buffer + coyote time
- staggered platforms
- side-firing Liquidity Blast
- mobile controls for left/right, jump, and blast
- camera follows XRPMan through a room wider than the viewport
- test room is procedural/temporary; final interior art comes later

The direct preview remains `?onfoot=1` so controller feel can be tested without replaying the flight mission.
