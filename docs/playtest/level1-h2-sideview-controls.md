# H2 Side-View Prototype Controls

Desktop:
- Left/right: A/D or arrow keys
- Jump: W, Up, or Space
- Liquidity Blast: X, F, or Enter

Mobile:
- bottom-left buttons: left/right
- bottom-center: JUMP
- bottom-right: BLAST
- tapping upper playfield also fires in the current facing direction

This file documents the temporary H2 playtest controls only. Final control presentation remains a later polish task.
